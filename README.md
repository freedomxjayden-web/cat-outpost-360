# 喵哨站 1.4.0 / CAT OUTPOST

網上遊玩：https://freedomxjayden-web.github.io/cat-outpost-360/

瀏覽器塔防生存遊戲，支援桌面及手機。部署、管理與升級炮塔，用震盪脈衝守住基地。新增可略過、可重看的首局教學、獨立教學暫停、欠款說明及返回作品集入口；經濟與戰鬥規則不變。

此公開庫只放 GitHub Pages 部署產物。下載 `play.html` 可離線開啟；首次操作後啟用音效。本機設定、紀錄及教學偏好不跨裝置同步，儲存受限制仍可遊玩。

操作：1–3 選塔；點格或方向鍵＋Enter 部署；M 管理；U／R 開升級／維修；Q 脈衝；空白暫停；Esc 關閉管理。手機先預覽再確認部署。

驗收針對本機完整原始碼：45 項測試、建置與瀏覽器流程通過。細節與限制見 `VERIFICATION-1.4.md`。實體手機與真人試用未完成。
